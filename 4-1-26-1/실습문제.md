## 실습 1: 오류 찾기 - 상속 선언

다음 코드에서 오류를 찾고 올바르게 수정하세요.

```cpp

#include <string>

class Vehicle {
private:
    std::string brand;
    int speed;

public:
    Vehicle(const std::string& brand, int speed);
    std::string getBrand() const;
    int getSpeed() const;
    void printInfo() const;
};
```

```cpp
#pragma once
#include "Vehicle.h"

class Truck : Vehicle {
private:
    int loadCapacity;

public:
    Truck(const std::string& brand, int speed, int loadCapacity);
    void printInfo() const;
};
```

```cpp

#include <iostream>

Truck::Truck(const std::string& brand, int speed, int loadCapacity)
    : brand(brand), speed(speed), loadCapacity(loadCapacity) {}

    std::cout << "브랜드: " << getBrand() << std::endl;
    std::cout << "속도: " << getSpeed() << std::endl;
    std::cout << "적재량: " << loadCapacity << std::endl;
}
```

## 실습 5: 상속 구조 전체 작성하기

다음 요구사항에 맞는 클래스를 **헤더 파일(.h)**과 **소스 파일(.cpp)**로 나누어 작성하세요.

### 요구사항

**부모 클래스: `Food`**
- **멤버 변수** (private)
  - `name` : 음식 이름 (string)
  - `calories` : 칼로리 (int)
- **생성자**
  - 기본 생성자: name="unknown", calories=0
  - 매개변수 생성자
- **멤버 함수**
  - `getName()`, `getCalories()` : getter
  - `printInfo()` : "음식: {name}, 칼로리: {calories}kcal" 출력

**자식 클래스: `Pizza` (Food를 public 상속)**
- **추가 멤버 변수** (private)
  - `size` : 사이즈 (string, "S"/"M"/"L")
  - `toppings` : 토핑 개수 (int)
- **생성자**
  - 매개변수 생성자: name, calories, size, toppings를 받아 초기화
- **멤버 함수**
  - `getSize()`, `getToppings()` : getter
  - `printInfo()` : 부모 정보 + "사이즈: {size}, 토핑: {toppings}개" 출력

### 동작 예시
```cpp
int main() {
    Food f1("샐러드", 150);
    f1.printInfo();
    // 음식: 샐러드, 칼로리: 150kcal

    Pizza p1("페퍼로니 피자", 800, "L", 3);
    p1.printInfo();
    // 음식: 페퍼로니 피자, 칼로리: 800kcal
    // 사이즈: L, 토핑: 3개

    // 부모 클래스의 getter 사용 가능
    std::cout << p1.getName() << std::endl;
    // 페퍼로니 피자

    return 0;
}
```
