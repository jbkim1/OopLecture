# 상속 - 실습정답

## 실습 1 정답: 오류 찾기 - 상속 선언

### 오류 목록
1. `class Truck : Vehicle` → `public` 키워드 누락 (기본이 private 상속이 되어 부모 public 멤버에 접근 불가)
2. 생성자에서 `brand(brand), speed(speed)` → 부모의 private 멤버를 직접 초기화할 수 없음. 부모 생성자 `Vehicle(brand, speed)`를 호출해야 함

### 수정된 코드

**Truck.h**
```cpp
#pragma once
#include "Vehicle.h"

class Truck : public Vehicle {   // public 추가
private:
    int loadCapacity;

public:
    Truck(const std::string& brand, int speed, int loadCapacity);
    void printInfo() const;
};
```

**Truck.cpp**
```cpp
#include "Truck.h"
#include <iostream>

Truck::Truck(const std::string& brand, int speed, int loadCapacity)
    : Vehicle(brand, speed), loadCapacity(loadCapacity) {}
// 부모 생성자 Vehicle(brand, speed)를 호출

void Truck::printInfo() const {
    std::cout << "브랜드: " << getBrand() << std::endl;
    std::cout << "속도: " << getSpeed() << std::endl;
    std::cout << "적재량: " << loadCapacity << std::endl;
}
```

## 실습 2 정답: 오류 찾기 - 부모 클래스 생성자 호출

### 오류 목록
1. **Shape.h**: `#include <string>` 누락 (std::string 사용하는데 헤더가 없음)
2. **Circle.cpp**: 생성자에서 부모 생성자 `Shape(color)` 호출이 빠져 있음. Shape에 기본 생성자가 없으므로 반드시 호출 필요

### 수정된 코드

**Shape.h**
```cpp
#pragma once
#include <string>          // 추가

class Shape {
private:
    std::string color;

public:
    Shape(const std::string& color);
    std::string getColor() const;
};
```

**Circle.cpp**
```cpp
#include "Circle.h"
#include <iostream>

Circle::Circle(const std::string& color, double radius)
    : Shape(color), radius(radius) {}
// Shape(color) 추가: 부모 생성자 호출

double Circle::getRadius() const {
    return radius;
}

void Circle::printInfo() const {
    std::cout << "색상: " << getColor() << std::endl;
    std::cout << "반지름: " << radius << std::endl;
}
```

## 실습 5 정답: 상속 구조 전체 작성하기

**Food.h**
```cpp
#pragma once
#include <string>

class Food {
private:
    std::string name;
    int calories;

public:
    Food();
    Food(const std::string& name, int calories);
    std::string getName() const;
    int getCalories() const;
    void printInfo() const;
};
```

**Food.cpp**
```cpp
#include "Food.h"
#include <iostream>

Food::Food() : name("unknown"), calories(0) {}

Food::Food(const std::string& name, int calories)
    : name(name), calories(calories) {}

std::string Food::getName() const {
    return name;
}

int Food::getCalories() const {
    return calories;
}

void Food::printInfo() const {
    std::cout << "음식: " << name << ", 칼로리: " << calories << "kcal" << std::endl;
}
```

**Pizza.h**
```cpp
#pragma once
#include "Food.h"
#include <string>

class Pizza : public Food {
private:
    std::string size;
    int toppings;

public:
    Pizza(const std::string& name, int calories, const std::string& size, int toppings);
    std::string getSize() const;
    int getToppings() const;
    void printInfo() const;
};
```

**Pizza.cpp**
```cpp
#include "Pizza.h"
#include <iostream>

Pizza::Pizza(const std::string& name, int calories, const std::string& size, int toppings)
    : Food(name, calories), size(size), toppings(toppings) {}

std::string Pizza::getSize() const {
    return size;
}

int Pizza::getToppings() const {
    return toppings;
}

void Pizza::printInfo() const {
    Food::printInfo();
    std::cout << "사이즈: " << size << ", 토핑: " << toppings << "개" << std::endl;
}
```
