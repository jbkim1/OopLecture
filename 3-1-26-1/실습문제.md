## 실습 5: 클래스 전체 작성하기

다음 요구사항에 맞는 `BankAccount` 클래스를 **헤더 파일(.h)**과 **소스 파일(.cpp)**로 나누어 작성하세요.

### 요구사항
- **멤버 변수** (모두 private)
  - `owner` : 계좌 소유자 이름 (string)
  - `balance` : 잔액 (int)
- **생성자**
  - 기본 생성자: owner="없음", balance=0
  - 매개변수 생성자: owner와 balance를 받아 초기화
- **멤버 함수**
  - `getOwner()` : 소유자 이름 반환
  - `getBalance()` : 잔액 반환
  - `deposit(int amount)` : 잔액에 amount를 더함
  - `withdraw(int amount)` : 잔액이 충분하면 amount를 차감, 부족하면 "잔액이 부족합니다." 출력
  - `printInfo()` : "소유자: {owner}, 잔액: {balance}원" 형식으로 출력

### 동작 예시
```cpp
int main() {
    BankAccount acc1("홍길동", 10000);
    acc1.deposit(5000);
    acc1.printInfo();       // 소유자: 홍길동, 잔액: 15000원

    acc1.withdraw(20000);   // 잔액이 부족합니다.
    acc1.withdraw(3000);
    acc1.printInfo();       // 소유자: 홍길동, 잔액: 12000원

    return 0;
}
```
