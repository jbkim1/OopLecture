# 클래스 선언 및 정의 - 실습정답

## 실습 1 정답: 오류 찾기 - 클래스 선언

### 오류 목록
1. `class Book` 뒤에 `{` (여는 중괄호)가 없음
2. `title`, `pages`의 접근 지정자가 없음 (기본은 private이지만 명시적으로 쓰는 것이 좋음)
3. 클래스 끝에 세미콜론(`;`)이 없음

### 수정된 코드
```cpp
#pragma once
#include <string>

class Book {               // { 추가
private:                   // 접근 지정자 명시
    std::string title;
    int pages;

public:
    Book(const std::string& title, int pages);
    void printInfo() const;
};                         // 세미콜론 추가
```

## 실습 2 정답: 오류 찾기 - 멤버 함수 정의

### 오류 목록
1. 생성자 정의에 `Book::` 범위 지정 연산자가 없음
2. `getTitle()` 함수 정의에 `Book::` 범위 지정 연산자가 없고, `const`는 선언에서만 사용
3. `getPages()` 함수 정의에 `const`가 빠져 있음 (선언과 불일치)

### 수정된 코드
**Book.cpp**
```cpp
#include "Book.h"
#include <iostream>

Book::Book(const std::string& title, int pages) : title(title), pages(pages) {}
// Book:: 추가

std::string Book::getTitle() const {
// Book:: 추가, const 유지 (선언과 일치시켜야 함)
    return title;
}

int Book::getPages() const {
// const 추가 (선언과 일치시켜야 함)
    return pages;
}

void Book::printInfo() const {
    std::cout << "제목: " << title << ", 페이지: " << pages << std::endl;
}
```

## 실습 4 정답: 코드 완성하기 - 멤버 함수 정의

**Car.cpp**
```cpp
#include "Car.h"
#include <iostream>

Car::Car() : model("unknown"), year(0), mileage(0) {}

Car::Car(const std::string& model, int year, int mileage)
    : model(model), year(year), mileage(mileage) {}

std::string Car::getModel() const {
    return model;
}

int Car::getYear() const {
    return year;
}

int Car::getMileage() const {
    return mileage;
}

void Car::drive(int km) {
    mileage += km;
}

void Car::printInfo() const {
    std::cout << "모델: " << model << ", 연식: " << year << ", 주행거리: " << mileage << std::endl;
}
```

## 실습 5 정답: 클래스 전체 작성하기

**BankAccount.h**
```cpp
#pragma once
#include <string>

class BankAccount {
private:
    std::string owner;
    int balance;

public:
    BankAccount();
    BankAccount(const std::string& owner, int balance);
    std::string getOwner() const;
    int getBalance() const;
    void deposit(int amount);
    void withdraw(int amount);
    void printInfo() const;
};
```

**BankAccount.cpp**
```cpp
#include "BankAccount.h"
#include <iostream>

BankAccount::BankAccount() : owner("없음"), balance(0) {}

BankAccount::BankAccount(const std::string& owner, int balance)
    : owner(owner), balance(balance) {}

std::string BankAccount::getOwner() const {
    return owner;
}

int BankAccount::getBalance() const {
    return balance;
}

void BankAccount::deposit(int amount) {
    balance += amount;
}

void BankAccount::withdraw(int amount) {
    if (balance >= amount) {
        balance -= amount;
    } else {
        std::cout << "잔액이 부족합니다." << std::endl;
    }
}

void BankAccount::printInfo() const {
    std::cout << "소유자: " << owner << ", 잔액: " << balance << "원" << std::endl;
}
```
