## 클래스 구조

### 부모 클래스: `Payment`

- **멤버 변수** (private): `amount` (int)
- **생성자**: 매개변수 생성자
- **멤버 함수**: `getAmount()`, `printReceipt()` (virtual)

### 자식 클래스: `CardPayment` (Payment를 public 상속)

- **추가 멤버 변수** (private): `cardNumber` (string)
- **생성자**: 매개변수 생성자 (부모 생성자 활용)
- **멤버 함수**: `getCardNumber()`, `process()`, `printReceipt()`

### 자식 클래스: `CashPayment` (Payment를 public 상속)

- **추가 멤버 변수** (private): `receivedAmount` (int)
- **생성자**: 매개변수 생성자 (부모 생성자 활용)
- **멤버 함수**: `getReceivedAmount()`, `process()`, `printReceipt()`

## 동작 예시

```cpp
int main() {
    CardPayment card(15000, "1234-5678-9012-3456");
    CashPayment cash(8000, 10000);

    // 부모 포인터 배열을 통한 호출
    Payment* payments[2];
    payments[0] = &card;
    payments[1] = &cash;

    for (int i = 0; i < 2; i++) {
        payments[i]->printReceipt();
        std::cout << "---" << std::endl;
    }
    // [카드] 15000원
    // 카드 결제 처리 중... 완료
    // 카드번호: 1234-5678-9012-3456
    // ---
    // [현금] 8000원
    // 현금 결제 처리 중... 완료
    // 거스름돈: 2000원
    // ---

    return 0;
}
```
